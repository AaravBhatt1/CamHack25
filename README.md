# CamHack25 Project

NOTE: This is a weekend hackathon project, so pls don't judge the code quality

Our project is an app that changes the way in which users can type on their keyboard. Instead of typing the 'A' key to type the character 'A', the user instead traces the character on the keyboard with their finger. This gives users more time to think of what they want to say.
